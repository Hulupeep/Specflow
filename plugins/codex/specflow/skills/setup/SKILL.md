Run `node <plugin-root>/scripts/setup.cjs TARGET` (use this installed plugin's actual root). The adapter supplies `--runtime codex`. Read both installation and strict readiness outcomes; preserve incomplete readiness and staged state. It requires the matching public `specflow` CLI on PATH. Do not install a different version silently, invoke providers or import private installers. Run `specflow doctor TARGET --json` for read-only local identity and repair details.
