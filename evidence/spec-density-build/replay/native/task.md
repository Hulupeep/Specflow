# Controlled decision replay

This fixture deliberately starts with seeded bad decisions. Assess them independently against the following stable acceptance; corrections may change the proposed decisions but not this acceptance. No product completion or deploy claim.

AC-OFFLINE: The selected bounded parser operation works offline; no required cloud service.
AC-CORRECTIONS: Owner corrections survive repeat parsing; generated cache cannot own the only correction copy.
AC-IDENTITY: Stable source identity distinguishes archives and survives sorting or rescanning.
AC-NETWORK: Private source content stays inside the approved local sandbox; it is never sent to a provider.
AC-REUSE: Reuse the established sandbox and canonical decisions; no duplicate unreviewed parser sandbox.
GATE-CHECKS: Execute all five scoped decision checks with no failures or skips before acceptance.
